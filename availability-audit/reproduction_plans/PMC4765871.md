**Summary.** The framework turns static single-cell expression snapshots into pseudo-time series and fits ODE models of transcriptional regulation to them. The steps are:
- **Embedding and branches.** A diffusion map embeds the cells. Branches are separated by an ad-hoc method: a Dijkstra shortest path between a chosen start and end cell, plus the Nn nearest neighbours of the path cells.
- **Pseudo-time.** Wanderlust orders the cells in each branch.
- **Candidate networks.** GENIE3 plus correlation signs give a coarse network, which limits the candidate models.
- **Models.** Each target gene gets Hill-function ODE models with AND (product) or OR (sum) logic over its inputs.
- **Fitting.** Models are fitted one subnetwork at a time by Metropolis MCMC, with Gaussian-process emulators (synthetic data) or piecewise-linear interpolators (real data) standing in for the inputs.
- **Model choice.** Models are compared with AIC/BIC and with Bayes factors from thermodynamic integration.

The paper claims the framework recovers logic gates and kinetic parameters on simulated data:
- **FFL.** On an OR-gate incoherent feed-forward loop (300 cells) it gets Bayes factor OR/AND > 100 and about 17% mean parameter error (14.5% with an informative prior on λ).
- **Toggle switch.** On a six-gene toggle-switch hierarchy (400 cells) the AND(A+, D−) model for gC wins, with about 6.8% error.
- **Haematopoiesis.** On mouse haematopoiesis qPCR data (Moignard et al. 2013; 597 cells, 18 TFs) it recovers a GATA2–GFI1–GFI1B subnetwork that agrees with the experimentally validated triad.

## 5. Reproduction plan

1. **Haematopoietic data first: deterministic data, least risk (Figure 7B/C, about 6 h).** Load the xlsx and apply Moignard QC (target 597 cells; per-type counts 123/124/121/116/113). Compute ΔCt per Moignard, keep the 18 TFs, and run destiny with sigma = 100.9 and 3 DCs. Target: three branches plus an HSC "fourth arm", and separation of the cell types. Then run GENIE3 and check that edges above 0.08 give a sparse network containing the GATA2, GFI1 and GFI1B inputs (supp. Fig. 29). Also check the paper's own branch-clustering accuracy without labels: errors of 1.3%, 7.4% and 10.3% for PreMegE, GMP and CLP with Nn = 15 (supp. §2.3.1).
2. **Shared inference pipeline (about 60 h, one-off).** Build:
   - the Hill-ODE model generator for AND, OR and mixed gates
   - an RK4 solver
   - Metropolis MCMC on log-parameters
   - GP emulators
   - thermodynamic integration
   - AIC/BIC

   Validate it on a toy model with known parameters before using it on paper data.
3. **Haematopoietic model selection (Figures 8 and 9).** Run Wanderlust (k = 15, l = 5) on the HSC → LMPP → GMP and HSC → LMPP → CLP cells, 3 replicates each. Pre-process as in supp. §2.3.2, then fit the 17 GATA2 models on CLP and the 4 + 4 GFI1/GFI1B models on GMP.
   - **Edges to recover:** GATA2 ← SCL (+), GATA2 ← GFI1 (−), GATA2 ← AND(GFI1, NFE2); GFI1 ← GFI1B (−); GFI1B ← GFI1 (−) and GATA2 (+).
   - **Supp. Table 8 (GATA2) AIC/BIC:** SCL −223/−229, GFI1 −214/−219, and(GFI1,NFE2) −211/−219, NFE2 −302/−308 (worst).
   - **Supp. Table 9:** for target GFI1, and(GATA2,GFI1B) −198/−206 collapses to GFI1B, and GATA2 alone gives −213/−218; for target GFI1B, and(GATA2,GFI1) −220/−228, or(GATA2,GFI1) −216/−224, GATA2 −212/−218, GFI1 −219/−224.

   Expect only qualitative agreement on edges.
4. **FFL simulation (Figures 2–4).** Choose σs, Δt and gX(t) so that supp. Fig. 12 is matched visually (expression reaches about 1000, pulse in gZ, t_stop ≈ 40). Simulate 300 cells, order them with Wanderlust (k = 18), compare with the deterministic run (Fig. 2A), then run model selection. Targets:
   - GENIE3 keeps edges with w ≥ 0.3, and r(gX, gY) ≈ 0.9
   - log-evidence about −385 (OR, gX → gZ ⊣ gY) against about −400 (inverted signs), and Bayes factor OR/AND > 100
   - mean MAP relative error about 17%, falling to 14.5% with an informative λ prior; posterior α/λ ≈ 400
   - supp. Table 4 modes for gZ: α 96.97, λ 0.2490, κ+ 417.1, h+ 14.16, κ− 264.3, h− 8.15

   Then run the three perturbations for Figure 4 (qualitative agreement of the gZ dynamics).
5. **Toggle switch (Figures 5 and 6, plus supplementary robustness if time allows).** Simulate 400 cells and run DM (σ = 1000, 3 DCs; target: an X shape with 4 branches and 4 significant eigenvalues). Cluster (Nn = 15), run Wanderlust (k = 18, 3 replicates), then GENIE3 (threshold 0.3) with correlation |r| > 0.5. Fit the gC candidate models on the two branches where gA is high. Targets:
   - AND(A+, D−) best; mean relative error about 6.8% (the gC + gD joint fit, Fig. 1H)
   - with threshold 0.1 and 94 models, |BIC|/|AIC| 590.0/581.8 for and(A+,D−) against 592.1/581.3 for and(or(A+,B−),D−); log-ML −566.195 against −567.455 (Bayes factor 3.53) (supp. Table 7)
   - noise robustness errors of 6.8, 7.6, 9.1, 5.1 and 8.2% (supp. Table 6)
   - clustering misclassification 7.4 ± 1.8% against 9.9 ± 1.7% (σ = 20) and 8.7 ± 2.5% against 14.1 ± 1.6% (σ = 80), low-dimensional against high-dimensional (supp. Table 1)

## 6. Risks and open questions

- **Simulation noise and input process are unspecified.** All synthetic results depend on σs, Δt and gX(t). Tune them to the supplementary example trajectories and report the chosen values. Exact parameter-error percentages are unlikely to match. Aim for the qualitative claims: the right gate wins, and errors are around 10–20%.
- **Manual choices.** Diffusion-map start and end cells and the GENIE3 thresholds were chosen by eye. Record seeds and cell indices, and run 3 to 5 alternatives.
- **Implementation differences.** destiny (2026) differs from the 2015 MATLAB diffusion-map code (sigma conventions and density normalization), and Wishbone's Wanderlust differs from the cyt MATLAB version. Prefer cyt3 `wanderlust.m` if MATLAB is available.
- **MCMC and thermodynamic-integration tuning is undocumented.** Bayes factors near 3.5 (toggle switch) are within Monte Carlo error. Only the "> 100" FFL result is a robust target.
- **Real-data model selection is fragile.** The top AIC values differ by a few units, and pre-processing (outlier filtering and Gaussian imputation of CT = 15) changes the data. Report edge recovery over replicates.
- **Compute.** About 2 h per model for synthetic data and about 10 h for the real subnetwork (supp. §2.4). Plan for parallel runs.
