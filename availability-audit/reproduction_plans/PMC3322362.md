# Reproduction plan: PMC3322362

## 1. Paper

| Field | Value |
| --- | --- |
| Title | Predicting RNA-Protein Interactions Using Only Sequence Information |
| Authors | Usha K Muppirala, Vasant G Honavar, Drena Dobbs |
| Journal | BMC Bioinformatics 12:489 |
| Year | 2011 |
| PMCID | PMC3322362 |
| DOI | 10.1186/1471-2105-12-489 |
| iCite RCR | 10.092 (paper_catalog.csv; 435 citations, NIH percentile 97.5) |

**Summary.** RPISeq classifies an (RNA, protein) pair as interacting or not from sequence alone. Each pair becomes a 599-dimensional vector:
- 343 protein features: normalized 3-mer frequencies over the 7-letter "conjoint triad" reduced alphabet {AGV}{ILFP}{YMTS}{HNQW}{RK}{DE}{C};
- 256 RNA features: normalized 4-mer frequencies.

Two Weka 3.7 classifiers are trained on these vectors: a Random Forest (20 trees, 10 features per split) and an SMO SVM (normalized polynomial kernel of order 2, C = 1, logistic calibration). Positives come from structure-derived benchmarks built from PRIDB: RPI2241 and its non-ribosomal subset RPI369. Negatives are random RNA–protein pairings. **Main claims:**
- 10-fold CV accuracy is 89.6% (RF) and 87.1% (SVM) on RPI2241, and 76.2% and 72.8% on RPI369.
- ROC AUC is 0.97/0.92 on RPI2241 and 0.85/0.81 on RPI369.
- Performance is comparable to a multi-feature method on yeast mRNA–protein data (text only).
- Models trained on PDB data recover 57–99% of NPInter ncRNA–protein interactions in five organisms.

## 2. Status

**Software: partly found.** RPISeq was a web server: http://pridb.gdcb.iastate.edu/RPISeq/ returns 503 over http, and https has a TLS name mismatch. The paper released no code. The lab's successor tool RPIMotif ships `createARFF_test.pl`. That script computes RPISeq's 343 conjoint-triad and 256 RNA 4-mer features (its comment reads "conjoint triads (Muppirala et al. 2011)"), alongside RPIMotif's own motif features. RPISeq's trained models are not there; RPIMotif's model (`RF_17910_ct.model`) is a different classifier.

## 6. Risks and open questions

- **The negative set dominates the result.** The one independent rerun found (IPMiner, PMC4979166) used the same positives with new negatives and got RF accuracy 0.646 and AUC 0.690 on RPI2241, against 0.896 and 0.97 in the paper. With the authors' own RPI2241 negatives this risk is gone for RPI2241. For RPI369 it remains: report the spread over seeds, not one number.
- **Sequence drift.** Using the authors' sequences avoids it. 59% of RPI2241 pairs sit on obsolete split-ribosome entries, so sequences refetched from the PDB may differ.
- **Version and inconsistency issues.** Weka's RandomForest changed across 3.7.x, so pin a 2011 version. The abstract and the Results disagree on the AUCs (0.96/0.92 vs 0.97/0.92 and 0.85/0.81), and the chain counts disagree (952/443 vs 2,042/841 IDs). Both are open questions for the authors.
- **NPInter.** Tables 2–3 and Figs 2A–B are lost with the 2011 database snapshot.

**Verdict:** The RPI2241 parts of Table 1 and Fig 1 should come close, because the authors' sequences and negatives are published in RPIMotif. The RPI369 parts are approximate, with a real risk of a large gap, because their negatives are lost. Fig 2C is approximate. Tables 2–3 and Figs 2A–B are not regenerable (the NPInter 2011 evaluation set is gone). About 1 week.
