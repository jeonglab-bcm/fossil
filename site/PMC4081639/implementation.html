lldmn: Mesh Log-Likelihood for the Dirichlet-Multinomial

Validating the compiled algorithm shipped with Yu & Shaw (2014), Bioinformatics 30(11):1547–1554

The supplementary lldmn R package ships the mesh algorithm only as precompiled static libraries (libloglikdmn-linux.a and libloglikdmn-mac.a, x86_64). Its DESCRIPTION declares License: GPL-2. No C++ source for the algorithm is included.

This analysis recovers what the compiled code does, validates it against the paper’s equations, and documents the differences.

Method

  1. Split the Linux archive (GCC 4.6.1, Ubuntu; symbols not stripped, no DWARF) into its 8 objects and decompiled every function with REA 6.8.0 (rea decompile-all --provider ghidra) on Ghidra 12.1.4 / JDK 21.
  2. Ran the authors’ macOS x86_64 library under Rosetta through a C driver (driver.c + stubs.c supplying operator new/delete, aborting on any other C++ runtime call).
  3. Compared over 324 inputs (paper Figs 2/4/5/6 settings, the vignette example, 300 random K=21 cases with counts up to 105 and ψ ∈ {0} ∪ [10−8, 10]): the binary, a Python reimplementation from the decompiled logic, and exact Eq. (6) via mpmath at 50 digits.

Recovered Algorithm

R entry point: loglikdmn::loglikdirmultinom_mesh(n, p, ψ)

if all n == 0: return 0
α = p / ψ
min_alpha = 1/δ + 1 = 6              (δ = 0.2)

# 1. VGAM warm-up (not described in the paper)
if any(n_i > 0 and α_i < 6):
    x_i = min(n_i, ceil(6 − α_i))   for those i, else 0
    total += exact product (Eq. 4/7)
    update (p, ψ) via Eqs (27)–(28);  n ← n − x

# 2. Bernoulli mesh steps (paper Eqs 20, 29–32)
while any(n > 0):
    x_i = min(n_i, floor(0.2 · α_i))   Eq. (30) + Eq. (32) cap
    total += Σ [x_k log p_k + D_20(ψ/p_k, x_k)] − D_20(ψ, Σx)
    update (p, ψ);  n ← n − x
return total

where D_20(x, y) = Σ_{n=2}^{20} (−1)^n φ_n(y) x^{n−1} / (n(n−1))
      φ_n(y) = B_n(y) − B_n  (Bernoulli polynomials)

Differences from the Paper

1. Undocumented exact warm-up

Before any Bernoulli step, every category with αi = pi/ψ < 6 gets up to ⌈6 − αi⌉ counts evaluated with the exact VGAM-style product. The paper’s mesh rule, Eq. (30) xi = ⌊αiδ⌋, is 0 whenever αi < 5. Implemented exactly as written, it would never advance such a category. The warm-up is what makes the algorithm terminate. It adds at most 6 terms per category, so the runtime claims are unaffected.

2. Large ψ produces zero Bernoulli steps

In the Fig. 2/4 setting (x = (2,3,1), p = (.2,.3,.5)), ψ ≥ 0.1 gives zero Bernoulli steps. The value reported as the “mesh algorithm” is entirely the VGAM-style product, written in ψ rather than ρ.

3. Fixed constants

m = 20 and δ = 0.2, as stated in the paper. ψ < 1 and ψ ≥ 1 use different but algebraically equal update formulas, matching Eqs (27)–(28).

4. Unpublished extras

The library also contains loglikdirmultinom_diff_{mesh,vgam,bern_approx} (log-likelihood differences for a second p vector). These are not exposed by the R wrapper.

Reproduce

clang -arch x86_64 -mmacosx-version-min=10.13 -w \
  driver.c stubs.c libloglikdmn-mac.a -o lldmn_driver

uv run --with mpmath==1.3.0 \
  python -I difftest/difftest.py ./lldmn_driver
