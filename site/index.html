fossil is an archive of methods from published computational papers. An AI agent rebuilds each one from the paper and whatever survived, and every figure is checked against the one in print.

Why bring a method back

  • Trust. A published result is a claim until someone reruns it. Most never are.
  • Reuse. Old methods still work on new data. A 2003 test for SAGE counts now scores CRISPR screens.
  • Recover. A rerun shows what the paper left out, like a step in Yu and Shaw that was never written down.
  • Rebuild once. The method comes back as open, tested code that anyone can run.

How a paper comes back

  1. The paper and whatever survived. Its text, figures, supplements, data and any code still online.
  2. An AI agent rebuilds the analysis with Paper2Repro, in one session and one pull request.
  3. A pipeline reruns it. The published figures are the answer key, and every verdict is computed, never typed.
