# Bundled example data

A small 6-premise outbreak **simulated** from the model, so the method can be
shown end to end without redistributing the paper's data. It is not the paper's
data and is not meant to reproduce the paper.

Generated by `scripts/make_example_data.py` (seed 7; 6 premises in a 10x8 km
domain; parameters alpha=(60,6), beta=(6,2); sequence length s=4000, substitution
rate m=1e-4).

| File | What |
| --- | --- |
| `example_epi.csv` | one row per premise: `premise, x_km, y_km, Tobs, Tend, Dobs` |
| `example_hamming.csv` | the 6x6 matrix of pairwise Hamming distances between the simulated genomes |
| `example_expected.json` | the simulation's ground truth: the true transmission tree and the true mean latency and mean transmission distance |

## Expected output

`example_expected.json` is produced by the **simulator**, not by `transtree`'s
inference. The tutorial infers the tree from `example_epi.csv` and
`example_hamming.csv` and checks it against this ground truth, so a match is a
real test of the inference, not a snapshot of its own output.

Compare the inferred most-likely source of each premise with `true_tree`
(a list of sources, one per premise; `-1` is the external source). The inference
should recover all but at most one source on this example.
