# PMC2909217 figure reproduction

You ZH, Yin Z, Han K, Huang DS, Zhou X. A semi-supervised learning approach to predict synthetic genetic
interactions by combining functional and topological properties of functional gene network.
*BMC Bioinformatics* 11:343 (2010). [doi:10.1186/1471-2105-11-343](https://doi.org/10.1186/1471-2105-11-343)

The authors' program and data (GeneticInterPred) are lost, so everything here is rebuilt from the paper's text:
the data from public archives, the method as the package [`../package`](../package) (`fgnssl`). The pipeline
reruns the paper's experiments, draws Figs 2 to 6 on the published figures' pixel grids, scores them against the
published ones, and writes [`../results.json`](../results.json).

## What the code does, against the paper

| Paper | Ours |
| --- | --- |
| Gold standard: Tong et al. 2004, ~4,000 SL/SS pairs among ~650,000 tested (132 queries x ~4,700 deletion strains). | Tong 2004 rows of BioGRID as SGD imported them on 2009-12-19 (3,873 rows, 3,411 pairs, 125 queries, all "Synthetic Lethality"). Non-SGI: Tong query genes x the non-essential Verified and Uncharacterized ORFs of SGD's 2009-12-05 tables (4,747 genes; essential = an inviable systematic null), minus the SGI pairs. |
| PPI from BioGRID, 12,990 interactions among 4,478 proteins (release and filter not stated). | Two-hybrid and Affinity Capture-Western interactions of the same release: 13,007 interactions, 3,915 proteins (the interpretable filter closest to the paper's count; see `results.json`). |
| Complexes from Gavin 2002 and Ho 2002 as cliques, about 49,000 interactions. | Each Gavin or Ho purification (bait and preys, Affinity Capture-MS rows of the same release) as a clique: 48,129 interactions. |
| 64 conditions: Cho 1998 (17), Eisen 1998 heat shock (6) and sporulation (9), Spellman 1998 (32); missing values by the condition mean. | SGD's processed copies of Cho 1998 (17), Chu 1998 sporulation (7), Spellman alpha factor (16) and elutriation (14): 54 conditions. Eisen's heat-shock series is only on the Wayback Machine. Genes missing from a set get the condition mean, as in the paper. |
| DCCA clustering; eq. 2 weights with L1 = 0.3. | `fgnssl.dcca` (as the paper describes it) and `fgnssl.edge_weights`: 249 clusters on 6,272 genes, W used as the tie strength and 1 / W as the path length. |
| 18 features from 10 properties (Table 2). | Average and absolute difference of 8 node properties, weighted shortest path and mutual neighbours (`fgnssl.network`). |
| SSL: Zhou et al. 2004, sigma and alpha not stated. | Label spreading, alpha 0.99, sigma chosen on the training labels by hiding a third of them. |
| SVM: LIBSVM, RBF, C and gamma by grid search. | scikit-learn's SVC (LIBSVM), 3-fold grid search over C 2^-1..2^9 and gamma 2^-9..2^1 on the training folds. |
| 1,500 + 1,500 pairs; 80% (5-fold), 50% (2-fold) and 20% training; five repeats averaged. | The same, with seeds 0 to 4; test scores ranked within each fold and pooled; repeats averaged at 26 score quantiles. |
| Table 1 and Fig. 6: KS test, SGI against non-SGI pairs. | scipy's two-sample KS on all SGI and all tested non-SGI pairs in the network (the paper does not say which pairs); densities as R's `density()`. |

## Run

From the repository root, with Python 3.12, Java 21 and Nextflow 26.04.3:

```bash
pip install -r PMC2909217/figure-reproduction/requirements.txt
```

```bash
nextflow run PMC2909217/figure-reproduction/main.nf --outdir results
```

The run takes about 13 minutes on 4 x86_64 cores. The check step fails if the fresh run differs from `output/` or `../results.json`. After an intended
change, run with `--update`, copy `results/` into `output/` (without `results.json`, `site/`, `package.json`)
and `results/results.json` to `../results.json`, and `results/site/index.html` to `site/PMC2909217/`.

CI: `.github/workflows/reproduce-pmc2909217.yml` runs the same command on every pull request that touches this
paper.

## Pipeline steps

1. **FETCH** the six inputs and check their SHA-256.
2. **PREPARE** the gold standard, edges, expression matrix and counts.
3. **FEATURES**: DCCA, eq. 2 weights, the 8 node properties on both networks, 18 features for 379,708 pairs.
4. **EXPERIMENTS**: SSL and SVM at 80/50/20% training, SSL on the binary network at 50%; 5 repeats.
5. **KS**: Table 1 and the densities.
6. **HYPOTHESES**: 9 variants on repeat 0 at 50% unlabelled.
7. **FIGURES**: Figs 2 to 6 drawn on the published figures, overlays, two-way scores at 2 px, controls.
8. **CLAIMS**: the claims of the text from our run; the arithmetic check on the paper's own tables.
9. **PACKAGE**: `check_package.py` on `../package`.
10. **RESULTS**: `results.json`, `check_results.py`, the comparison with the committed outputs, the page.

## Limits

- The data are the closest public versions, not the paper's: SGD's copy of BioGRID of 2009-12-19 (the paper's
  release is not stated), our PPI filter (13,007 interactions against 12,990), 54 of the 64 expression
  conditions, 125 of the 132 Tong query genes.
- Sigma, alpha, the SVM grid, the feature scaling, the 18-feature layout and the seeds are ours; each is in
  `results.json` with how much it moves the result.
- The published figures are PMC's web JPEGs (about 530 px wide), not the authors' originals; the scores use a
  2 px tolerance on that grid.
- Figs S1 to S32 (Additional file 1) are computed (`output/densities.json`) but not drawn or scored.
