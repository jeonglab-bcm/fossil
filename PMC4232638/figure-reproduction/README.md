# PMC4232638 figure reproduction

Martelotto LG, Ng CKY, De Filippo MR, et al. Benchmarking mutation effect prediction algorithms using
functionally validated cancer-related missense mutations. *Genome Biology* 15:484 (2014).
[doi:10.1186/s13059-014-0484-1](https://doi.org/10.1186/s13059-014-0484-1). CC BY 4.0; data CC0.

`published/` holds renders of the paper's figures, made once from the PMC PDFs by
`pipeline/render_published.py` (CC BY 4.0, attribution above), and `fig1_reading.json`, the predictor order
and dendrogram clades of Fig. 1 transcribed by eye. Nothing else of the paper is in this folder: the pipeline
downloads the article PDF and XML and 28 supplement files from PMC's open-access bucket (Europe PMC as a
fallback) and checks their SHA-256.

## Run

From the repository root:

```bash
sudo apt-get install -y poppler-utils
pip install -r PMC4232638/figure-reproduction/requirements.txt ./PMC4232638/package
nextflow run PMC4232638/figure-reproduction/main.nf --outdir results
```

`--sources DIR` copies the inputs from a local folder (`paper.pdf`, `PMC4232638.xml`, `supp/`) instead of
downloading them. The whole run takes about 90 seconds on four cores (the combinations: 11,253 rules x 1,000
splits x 2 data sets x 2 runs, as matrix products). CI (`.github/workflows/reproduce-pmc4232638.yml`) runs the
same command on every change to this folder, the package or the results page.

## Pipeline steps

1. `FETCH`: download the inputs and check their SHA-256.
2. `PUBLISHED_VALUES`: read the printed values (`published_values.json`; Additional files 17 and 18, 270,072
   values, stay in the work folder).
3. `READ_FIGURES`: read the drawn values (`figure_values.json`).
4. `ANALYZE`: run every analysis with `mutbench` (`analysis.json`): seeds are fixed, so a rerun gives the same
   numbers.
5. `COMPARE`: the comparison and the claims (`comparison.json`, `claims.json`).
6. `FIGURES`: our figures on the published frames and the overlays.
7. `PACKAGE`: `check_package.py ../package` (wheel, fresh install, tests, tutorial rerun).
8. `RESULTS`: `results.json`, `check_results.py --write`, the page, `report.md`; `check_reproduction.py`
   compares the fresh run with everything committed.
9. `CHECK`: fails the run when any check fails.

## Limits

- The paper's random seeds are unknown, so results that come from resampling (intervals, combination means,
  rankings and counts near a cutoff) can only agree within the Monte Carlo spread. Rankings of near ties and
  counts near a cutoff change between our own runs.
- Fig. 1's call heat maps: we compare each row's shares of non-neutral, neutral and missing calls, not the
  order of the 3,591 SNVs (the paper clustered them; ours are sorted by their calls). The leaf order of the
  dendrograms is a drawing choice; we compare the clades and the join heights. The call heat maps and
  dendrograms of Additional files 4, 10 and 12 are not compared, only their kappa heat maps.
- In Additional files 24 and 26 we compare the hinges and medians of the box plots, not the whiskers or the
  outlying points, and draw only the boxes and medians.
- The predictors are not rerun: their calls and scores are those frozen in Additional file 2 (several of the
  services are gone).
