# PMC4457112 figure reproduction

Cohen AM, Smalheiser NR, McDonagh MS, Yu C, Adams CE, Davis JM, Yu PS. Automated confidence ranked classification
of randomized controlled trial articles: an aid to evidence-based medicine. *J Am Med Inform Assoc*
22(3):707–717 (2015). [doi:10.1093/jamia/ocu025](https://doi.org/10.1093/jamia/ocu025)

The paper trained two linear SVMs that give every human-related MEDLINE citation of 1987–2012 a confidence
that it reports a randomized controlled trial, with the MEDLINE publication type Randomized Controlled Trial
(RCT_PT) as the label: CITATION_PLUS_MESH, which also reads the MeSH indexing, and CITATION_ONLY, which reads
only the citation. It released them only as the RCT Tagger web service at arrowsmith.psych.uic.edu, which
answers HTTP 503; no code, model or scores were published, and the methods supplement (feature sets, the
PubMed query, the confidence method) is not in PMC and returned 403 to us. This pipeline rebuilds the method
from the paper's text as the package [`rctconf`](../package/), retrains both models on the PubMed 2026
baseline, and compares every cell of Tables 1–3 and every claim of the text.

Both models came back. Retrained on 6,164,168 human-related MEDLINE citations of 1987-2012 (278,869 tagged RCT
against the paper's 277,789), the CITATION_PLUS_MESH model scores AUC 0.9738 on 2011 and 0.9715 on 2012 (paper 0.973 and
0.972) and the CITATION_ONLY model 0.9681 and 0.9658 (paper 0.966 and 0.965). Every AUC, average precision, F1 and accuracy
of Tables 1 and 2 is within 0.008 of the paper's; at the printed three decimals 12 of 42 cells match exactly. Table 3's
pattern holds: forward selection beats CHISQ filtering, dropping all but the strongest weights costs almost nothing, and
adding publication types raises AUC a little while average precision, F1 and MSE get worse.

What does not come back depends on the lost supplement or on manual labels: the number of feature sets chosen (10 and 13
here, 7 and 10 in the paper; as a hypothesis test, comparing AUC at three decimals gives 7 and 7, which matches the paper
for CITATION_ONLY only), the total feature count (54 million against about 45), the size of the CHISQ models (the test's
threshold is not given), the zero-centred-sigmoid MSE, the F1 of the single feature "randomized" (0.58 against about
0.72), the flatness of the training-fraction curve (AUC +0.0026 from 5% to 10%), the disagreement counts at 0.95, 0.50
and 0.05 (set by the lost confidence method), the acute cholecystitis example (its search is lost), and Fig. 1, the 2014
sample and the kappa (the reviewed articles were never released). The arithmetic check found four slips in the paper: 2751 of 3088 is 89%, not 85%;
5% of 277,789 is 13,889, not 12,900; 7,900 + 12,900 is about 21,000, not 20,000; and Table 3's feature counts give a
431-fold reduction for CITATION_ONLY, not 300-400.

**The main claim holds: both rebuilt models rank RCTs with AUC near 0.97, the MeSH model ahead, as in the paper. The
claims that do not match come from the lost supplement (feature sets, CHISQ test, confidence method) and from manual
labels that were never released.**

## Run

```bash
pip install -r PMC4457112/figure-reproduction/requirements.txt ./PMC4457112/package
nextflow run PMC4457112/figure-reproduction/main.nf --outdir results
```

The default run takes about 10 minutes on a 4-core runner: the mini reproduction (three baseline files,
`pubmed26n0676`, `0680` and `0712`, downloaded and SHA-256 checked, then extraction, dataset, features,
forward selection, all eight models and scoring) compared with `output/mini` at a relative tolerance of
1e-6; the comparison of the committed full run with the paper; the package check; `results.json`; the page;
the check against every committed output. `--full` reruns everything from the 1,334 baseline files instead
of reading the committed full run: about 4 hours on 4 cores with 16 GB of memory (forward selection runs two
candidates at a time; each LIBLINEAR fit on the 199,000-citation half-sample peaks near 5 GB). CI runs the
default on every change and `--full` only when started by hand (`full = true`). `--extract` reads Tables 1–3
again from the paper's PMC XML.

## Pipeline steps

1. `PUBLISHED_VALUES`: Tables 1–3 as printed (`output/published_values.json`, read from the PMC XML by
   `extract_published.py`).
2. `MINI`: the mini reproduction.
3. `FULL`: the committed full run, or with `--full` the whole run: extraction (MD5 of each file checked
   against NLM's `.md5`, SHA-256 recorded), dataset, features, forward selection and models, variants,
   scoring, topic, single feature, training fraction.
4. `PACKAGE`: `check_package.py` on `rctconf`.
5. `RESULTS`: `compare.py`, `build_results.py` (then `check_results.py --write`), `make_results_check.py`,
   `build_page.py`, `check_reproduction.py`.
6. `CHECK`: fails unless every check passed.

## Limits

- **The data are today's MEDLINE.** Older PubMed baselines are not distributed. Our dataset query was chosen by
  matching the paper's RCT_PT count among four candidates (`found_by_search`), which is why no table item can be `exact`.
- **The supplement is lost.** Feature sets, tokenization details, the LIBLINEAR solver and C, the selection rule, the
  CHISQ test and the confidence method are our choices, each listed in `results.json` with its sensitivity.
- **Forward selection used one 2-fold split per candidate** instead of 5x2 cross-validation, to fit the run into hours;
  the final models are cross-validated 5x2 as in the paper.
- **The confidence is not the paper's.** Our sigmoid is fitted to out-of-fold margins (Platt). The paper's extension of
  Ruping's method is described only in the supplement; it sets the counts at 0.95 and 0.05.
- **The cholecystitis search is ours** (topic terms with the Robinson and Dickersin filter). Table S2 is lost.
- **Not attempted:** Fig. 1, the 2014 sample, the kappa and the supplement's figures and tables, which need manual
  labels or the supplement.
- **Logistic regression** was dropped from the hypothesis tests: on 54 million features LIBLINEAR's primal solver ran over
  15 minutes per model here.
- **The full run is not repeated by CI.** CI repeats the mini run (three baseline files, every step) and recomputes every
  comparison from the committed full outputs; the full run (`--full`, about 4 hours) runs only when started by hand.
