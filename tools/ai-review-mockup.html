The text follows the rules of STE80 Humanizer (MIT): one idea per sentence, active voice, plain words, no semicolons or dashes. A checker from the same project reads each answer and writes its notes to the CI log.

Table 5: agrees (the reviewer changed it from partly), why it matched

35 of 36 rates match. For set 3 (parametric) our run gives 0.13 and the paper prints 0.02. On 400 more data sets the rate is 0.050. So the 0.13 came from chance in our first 100 data sets.

Fig. 4 right: differs, why it did not fully match

⚠️ Text: globaltest is close to the mean: differs, worth a look

The largest gap is 0.06 (set 9: 0.86 against 0.92). We counted a gap as close when it was 0.05 or less.

Worth a look: the item's own cause says chance explains this gap. The 99% band for two shares of 100 is ±0.12. The paper's own tables differ by up to 0.04. We chose the 0.05 limit, and the paper does not give one. So the verdict may be too harsh. A reviewer can change it with a review block.

Case 7

The AI step could not run

Three things stop the review: no API key (every PR from a fork), an API error, or an answer that skips a changed item. Then the check fails.
