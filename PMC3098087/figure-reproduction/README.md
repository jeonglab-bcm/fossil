# PMC3098087 figure reproduction

Blagus R, Lusa L. Class prediction for high-dimensional class-imbalanced data. *BMC Bioinformatics*
11:523 (2010). [doi:10.1186/1471-2105-11-523](https://doi.org/10.1186/1471-2105-11-523). CC BY 2.0.

The images in `published/` are the paper's figures and the supplement figures we compare against,
rasterized at 144 dpi from the published PDFs by `pipeline/figures.py` (CC BY 2.0, attribution
above). Nothing else of the paper is in this folder: the pipeline downloads the paper, its six figure
files, Additional files 1-14, the Sotiriou et al. (2003) data and sma 0.5.15, and checks their SHA-256.

## Run

```bash
bash PMC3098087/figure-reproduction/pipeline/install_r_deps.sh   # Ubuntu 24.04: R 4.3.3 and the pinned R packages
R CMD INSTALL PMC3098087/package
pip install -r PMC3098087/figure-reproduction/requirements.txt
nextflow run PMC3098087/figure-reproduction/main.nf --outdir results
```

Options: `--full` reruns every replicate of every setting and design (about 4 hours on 4 cores) and
builds everything from the fresh summary; `--check_reps N` reruns the first N replicates (default 3);
`--sources DIR` uses local copies of the downloads; `--cores N`.

The workflow `.github/workflows/reproduce-pmc3098087.yml` runs the default pipeline on pull requests
and pushes that touch this paper (about 15 minutes), and the full rerun when started by hand with
`full`.

## Pipeline steps

1. `FETCH`: download and check every input.
2. `EXTRACT`: the published values from the PDFs.
3. `READ_DATA`, `PORT_CHECK`: the breast cancer data; DLDA and DQDA against sma.
4. `SIMULATE`: rerun the first replicates of every setting and design (all with `--full`) and summarize.
5. `HYPOTHESES`: the SVM grid and the DQDA AUC scores.
6. `COMPARE`, `FIGURES`, `CLAIMS`: every published value against ours; renders and overlays; the claims.
7. `PACKAGE`: the R package check.
8. `RESULTS`, `CHECK`: `results.json`, the page, and the check that the run equals the committed outputs.
